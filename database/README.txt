SMS 2 – Database & Security Adoption
====================================

1. Start Apache + MySQL (XAMPP)
2. Install schema (once):
     C:\xampp\php\php.exe C:\xampp\htdocs\SMS2_system\database\install.php
3. Open setup and create YOUR Super Admin (no demo accounts):
     http://localhost/SMS2_system/setup/
4. After setup, add staff/student users in User Management.

What install creates:
  - roles, role_permissions, system_settings, empty users table

What install does NOT create:
  - demo logins / sample users
